# Highlights

- Four 3-h runs profile native vs containerised inference on a Raspberry Pi 5
- Power advantage reverses once normalised: energy per inference is 2.3% higher
- The 45.6% mean latency gap narrows to 1 ms at the 95th percentile
- Host and container differed in runtime version, so overhead is not attributable
- 311,683 quiescent frames, zero false positives; 4 intrusions all routed alike
